# قسط‌یار (GhestYar)

اپلیکیشن اندروید کاملاً شخصی و آفلاین برای مدیریت وام‌ها و اقساط — بدون نیاز به اینترنت، حساب کاربری یا سرور.

## امکانات

- ثبت وام و تولید خودکار اقساط با رعایت دقیق تقویم شمسی (از جمله «قانون روز ۳۱»)
- مشاهده اقساط معوق، پرداخت‌شده و آینده در ۴ تب جداگانه
- ثبت پرداخت با دو ضربه سریع (Double Tap) روی هر قسط
- ویرایش مستقل هر قسط (مبلغ، تاریخ، توضیحات) با فشار طولانی (Long Press)
- گزارش ماهانه با انتخاب سال، نوع گزارش و ماه (نمایش افقی ماه‌ها طبق منطق هوشمند)
- حداکثر دو هشدار اعلان قابل تنظیم برای هر وام + هشدار ویژه ۳ قسط معوق یا بیشتر
- پشتیبان‌گیری و بازیابی کامل اطلاعات (فایل JSON)
- پشتیبانی کامل از فارسی، راست‌چین (RTL)، اعداد فارسی و تاریخ شمسی
- طراحی مینیمال با رنگ اصلی سبزآبی (Teal) و حالت روشن/تاریک

## فناوری‌ها

Kotlin · Jetpack Compose · Material 3 · Room · Coroutines/Flow · Navigation Compose · WorkManager/AlarmManager · Coil

هیچ کتابخانه غیرضروری (مثل Hilt، Retrofit یا Firebase) استفاده نشده تا اپ سبک و ساده بماند.

## نکات فنی مهم

- **تاریخ شمسی**: الگوریتم تبدیل جلالی↔میلادی به‌صورت داخلی و بدون وابستگی خارجی پیاده‌سازی و
  با تاریخ‌های نوروز رسمی چند سال اخیر تست شده است (`domain/calculator/PersianDateConverter.kt`).
- **ذخیره‌سازی**: تمام تاریخ‌ها میلادی (ISO-8601) و مبالغ Long ذخیره می‌شوند؛ تبدیل به شمسی/فارسی
  فقط در لایه نمایش انجام می‌شود.
- **تصویر وام**: بلافاصله بعد از انتخاب از گالری به فضای داخلی اپ کپی می‌شود (نه فقط ذخیره URI)
  تا بعد از ری‌استارت گوشی از بین نرود.
- **وضعیت قسط** هرگز ذخیره نمی‌شود؛ همیشه از روی `dueDate`/`paidDate` محاسبه می‌شود.

## ⚠️ قدم ضروری قبل از Build: افزودن فونت Vazirmatn

به دلیل محدودیت محیط تولید این پروژه (نبود دسترسی اینترنت)، فایل‌های باینری فونت همراه کد نیستند
و **باید یک‌بار به‌صورت دستی اضافه شوند**، وگرنه پروژه Build نمی‌شود:

1. به صفحه رسمی فونت بروید: https://github.com/rastikerdar/vazirmatn/releases
2. آخرین نسخه را دانلود کنید و از پوشه `fonts/ttf` این ۴ فایل را بردارید:
   - `Vazirmatn-Light.ttf`
   - `Vazirmatn-Regular.ttf`
   - `Vazirmatn-Medium.ttf`
   - `Vazirmatn-Bold.ttf`
3. آن‌ها را در مسیر `app/src/main/res/font/` با همین نام‌های **حروف کوچک** کپی کنید:

```
app/src/main/res/font/vazirmatn_light.ttf
app/src/main/res/font/vazirmatn_regular.ttf
app/src/main/res/font/vazirmatn_medium.ttf
app/src/main/res/font/vazirmatn_bold.ttf
```

(نام فایل در Android باید فقط شامل حروف کوچک انگلیسی، عدد و `_` باشد.)

## نحوه Build (لوکال، در Android Studio)

1. فونت‌ها را طبق بخش بالا اضافه کنید.
2. پروژه را در Android Studio (نسخه پایدار جدید، مثلاً Iguana یا بالاتر) باز کنید.
3. اگر Android Studio درباره Gradle Wrapper هشدار داد (چون فایل باینری `gradle-wrapper.jar` در
   این پروژه نیست)، اجازه دهید Android Studio آن را خودکار بسازد، یا در ترمینال دستور زیر را
   بزنید (نیاز به نصب Gradle به‌صورت جداگانه دارد):
   ```
   gradle wrapper --gradle-version 8.7
   ```
4. Sync و سپس Run را بزنید.

## نحوه تولید APK

- **از Android Studio**: منوی `Build > Build Bundle(s) / APK(s) > Build APK(s)`
- **از ترمینال**: `./gradlew assembleDebug` (بعد از ساخت Wrapper طبق بالا)
- **از GitHub Actions**: با هر Push به شاخه `main`، اکشن `android-build.yml` به‌طور خودکار APK
  دیباگ می‌سازد و به‌عنوان Artifact قابل دانلود است. با ساخت یک Tag به شکل `v1.0.0` و Push آن،
  یک GitHub Release همراه با APK ساخته می‌شود.

## ساختار پروژه

```
app/src/main/java/ir/ghestyar/app/
├── data/            # Entity، DAO، Database، Repository، Backup
├── domain/          # منطق محاسبه تاریخ/اقساط، مدل‌ها، اعلان‌ها
├── presentation/    # ViewModel و صفحات Compose هر بخش (home, addloan, loandetail, settings)
├── ui/              # Theme، Typography، رنگ‌ها، کامپوننت‌های مشترک
└── utils/           # ابزارهای عمومی (اعداد فارسی، مدیریت تصویر)
```

## پشتیبان‌گیری و بازیابی

از صفحه تنظیمات:
- **تهیه نسخه پشتیبان**: یک فایل `.json` شامل تمام وام‌ها، اقساط، هشدارها و تنظیمات می‌سازد که
  می‌توانید در حافظه گوشی یا هر سرویس ابری ذخیره کنید.
- **بازیابی نسخه پشتیبان**: فایل قبلی را انتخاب کنید؛ بعد از تأیید صریح، تمام اطلاعات فعلی با
  اطلاعات فایل جایگزین می‌شود.

فایل پشتیبان شامل `schemaVersion` است تا در آینده اگر ساختار دیتابیس تغییر کند، فایل‌های قدیمی
همچنان (با Migration مناسب) قابل بازیابی باشند.

## محدودیت‌های شناخته‌شده این نسخه

- ورودی تاریخ در فرم‌ها به‌صورت متنی (`۱۴۰۵/۰۶/۱۵`) است؛ افزودن یک DatePicker شمسی گرافیکی
  اختصاصی می‌تواند در نسخه بعدی UX را بهتر کند.
- فایل باینری `gradle-wrapper.jar` باید طبق بخش Build بالا یک‌بار ساخته شود.
- تصاویر وام در فایل Backup گنجانده نمی‌شوند (فقط مسیر فایل داخلی)، تا حجم Backup کوچک بماند.
